Task 1: Java Basics & OOP Fundamentals

This folder contains the implementation of core Java concepts as part of my initial internship deliverables. 
The project is divided into two modules focusing on Object-Oriented Programming and Data Handling.

📁 Files in this Task
WarehouseSystem.java: A backend logic demonstration for a Smart Warehouse. It implements Inheritance, Abstraction, Polymorphism, and Encapsulation using a product inventory theme.  
DataAnalytics.java: A module demonstrating proficiency in Java Control Flow and Array Operations. It includes logic for summation, identifying peak values, filtering data, and linear search algorithms.

🛠️ Key Technical Concepts Applied
Encapsulation: Protecting internal state using private fields and public accessors.  
Polymorphism: Overriding methods to provide specific logic for different object types.  
Control Structures: Utilizing for, while, and if-else blocks for efficient data processing.  
Abstraction: Defining abstract base classes to establish a blueprint for specialized subclasses.  

🚀 How to RunNavigate to the task1 directory.

Compile the files:
Bash:

javac WarehouseSystem.java DataAnalytics.java

Execute the programs:
Bash

java WarehouseSystem
java DataAnalytics
