Task 2: Console-Based Application Development
This folder contains the implementation of a functional mini-project as part of my second internship milestone. The project focuses on integrating Java fundamentals into a cohesive, user-interactive system.

📁 Files in this Task
StudentManager.java: A comprehensive Academic Record Management System. It serves as a centralized tool for registering students, calculating grades, and performing data lookups through a menu-driven interface.

🛠️ Key Technical Concepts Applied
- Interactive User Input: Utilized the Scanner class to handle real-time data entry and system navigation.
- Complex Conditional Logic: Implemented multi-level if-else structures to assign formal academic grades based on raw examination scores.
- Search Algorithms: Developed a linear search mechanism to retrieve specific records from array structures using string comparison.
- Array Management: Managed parallel arrays to store and synchronize student names and their corresponding marks.

🚀 How to Run
Navigate to the task2 directory.

Compile the file:
javac StudentManager.java

Execute the program:
java StudentManager
